# Луми · Тропа слов

Бесплатная тестовая игра для изучения кабардинского и балкарского языков. Меню на русском; обучающие слова и покупки имеют перевод.

Игра работает в браузере. На iPhone откройте её в Safari и выберите «Поделиться» → «На экран Домой». Для офлайн-игры первый запуск требует интернета и завершения загрузки ресурсов.

Инструкции: install.html. Авторы и лицензии озвучки: credits.html. Копия для компьютера: lumi-offline.zip (распаковать и открыть word-platformer.html).

Прогресс хранится отдельно в браузере каждого игрока. Экспорт и импорт сохранения находятся в настройках. Очистка данных браузера, смена телефона или адреса требуют переноса сохранения. Обновления по прежнему адресу сохраняют совместимые данные.

Это тестовая версия: синтетическое произношение ещё требует независимой проверки носителями языка. Рекламы и встроенных платежей нет. Лицензии источников перечислены в credits; лицензия модели не объявляется автоматически лицензией всего кода игры.

Помощь родителям: `help.html` и отдельный Telegram-бот [@lumiZV_bot](https://t.me/lumiZV_bot?start=lumi_help). Переход находится в меню «Для взрослых». Заявки отправляются после подтверждения; статус публикации проверяется отдельно. Игра не отправляет боту сохранения или сведения об игроке.
